# Campus Life — Frontend Client

Клієнтська частина вебплатформи **«Campus Life»** — інтерактивного цифрового двійника студентського гуртожитку. Інтерфейс розроблений на React + TypeScript і забезпечує взаємодію з інтерактивною картою, бронювання ресурсів, участь в івентах та перегляд стрічки новин.

---

##  Технологічний стек
* **Фреймворк:** React 18
* **Мова програмування:** TypeScript
* **Інструмент збірки:** Vite
* **Менеджер пакетів:** npm
* **Стилізація:** Tailwind CSS + Vanilla CSS
* **Глобальний стан:** Zustand
* **Запити до API:** Axios + @tanstack/react-query
* **Авторизація:** MSAL (@azure/msal-browser) для Microsoft Entra ID (SSO)

---

## Структура папок клієнта
* `src/` — вихідний код програми:
  * `api/` — клієнти запитів до API (axios-інстанс, ендпоінти, конфігурація MSAL).
  * `components/` — перевикористовувані UI-компоненти (карта, заголовки, панелі деталей кімнат).
  * `pages/` — сторінки додатку (карта, бронювання, стрічка новин, профіль користувача, статистика).
  * `store/` — глобальні сховища Zustand.
  * `types/` — типізація даних TypeScript.
  * `utils/` — допоміжні утиліти (форматування дат, парсинг тощо).
* `public/` — статичні ресурси (іконки, SVG-карти).

## 🚀 Встановлення та запуск
Детальна покрокова інструкція для розгортання всього проєкту через Docker Compose міститься у супровідному файлі **INSTALLATION.docx** (або **INSTALLATION.pdf**), який додається до проєкту.

### Запуск окремо через Docker:
Виконується з папки `backend` (де знаходиться спільний `docker-compose.yml`):
```bash
docker compose up frontend --build -d
```
Клієнтська частина буде доступна за адресою: **[http://localhost:5175](http://localhost:5175)**

### Локальний запуск (без Docker):
Якщо ви бажаєте запустити клієнтську частину безпосередньо у вашому середовищі Node.js:
1. Переконайтеся, що встановлено Node.js (версії 18+).
2. Створіть `.env` на основі `.env.example` у папці `frontend`.
3. Встановіть залежності та запустіть сервер розробки:
   ```bash
   npm install
   npm run dev
   ```
4. Відкрийте браузер за адресою: **[http://localhost:5173](http://localhost:5173)**

## Якість коду та стандарти розробки
Для підтримки високої якості коду та єдиного стилю використовуються ESLint та Prettier. Виконуйте ці перевірки перед комітами:

### 1. Перевірка лінтером та збірка:
```bash
npm run build
npm run lint
```

### 2. Автоматичне виправлення помилок стилю:
```bash
npx eslint . --fix
```
