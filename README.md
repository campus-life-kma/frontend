# Campus Life - Frontend
Це клієнтська частина вебдодатка «Campus Life» — інтерактивного цифрового двійника студентського гуртожитку.
Проєкт розроблено за допомогою React, TypeScript та Vite.

## Технологічний стек
- **Фреймворк:** React 18
- **Мова:** TypeScript
- **Збірка:** Vite
- **Менеджер пакетів:** npm

### Бібліотеки:
 - `react-router-dom` - для навігації між сторінками (наприклад, перехід з карти в профіль).
 - `axios` - для зручних запитів до вашого бекенду.
 - `@tanstack/react-query` - кешує дані, показує стан завантаження (isLoading) і позбавляє необхідності писати купу useEffect.
 - `zustand` - менеджер станів.
 - `@tailwindcss/vite` - стилі.
 - `prettier` - правила оформлення коду.

## Перед запуском додайте .env за прикладом і заповніть його своїми даними

## Запуск проєкту локально (без Docker)
Якщо ви хочете запустити проєкт без контейнеризації, переконайтеся, що у вас встановлено [Node.js](https://nodejs.org/) (версія 18+) та npm.

0. Створіть файл `.env` у корені папки frontend на основі `.env.example`

1. Встановіть залежності:
```bash
npm install
```

2. Запустіть сервер для розробки:
```bash
npm run dev
```

3. Відкрийте браузер за адресою http://localhost:5173
4. Треба переналаштувати параметри cors у `backend/core/settings.py`

## Запуск через Docker
Для гарантовано ідентичного середовища у всіх розробників рекомендується використовувати [Docker Desktop](https://www.docker.com/products/docker-desktop/).

0. Створіть файл `.env` у корені папки frontend на основі `.env.example`

1. Запуск через docker-compose (виконується з папки backend)
```bash
docker-compose up frontend
```

2. Додаток буде доступний за адресою: http://localhost:5175

## Структура проєкту
 - `src/api` - api запити.
 - `/src/assets` - статичні файли (SVG-план гуртожитку, іконки).
 - `/src/components` - перевикористовувані UI-компоненти (кнопки, попапи, карта).
 - `/src/pages` - головні сторінки додатка (Карта, Профіль, Авторизація).
 - `/src/store` - глобальні стани додатка.
 - `/src/types` - інтерфейси TypeScript.
